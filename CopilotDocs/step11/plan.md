# Step11 Implementation Plan: 界面表现优化

## 目标
- 为主界面添加轻量 Compose 动画，提升页面切换、消息出现和列表选择反馈的顺滑度。
- 曲谱 JSON 校验失败时给出更明确的位置提示，帮助用户定位导入或手动创建中的问题。
- 播放配置页保存成功后使用屏幕中下方 Snackbar 提示“设置已保存”，并自动返回首页。
- 队列模式下用带顺序数字的复选列表替代手动输入队列序号。

## 范围内
1. 曲谱校验定位：
   - 保持 `ScoreParseResult.Failure(message: UiText)` 对外接口不变。
   - JSON 语法错误显示来源和行列；字段校验错误显示字段名，并尽量附带字段所在行列。
   - 覆盖 `name`、`bpm`、`time_signature`、`notes` 的严格校验失败。
2. 播放配置体验：
   - `PlaybackConfigDraft.queueText` 继续作为持久化队列格式。
   - 队列模式中按曲谱列表显示复选项；点击顺序决定播放顺序，并显示 1、2、3 等选中编号。
   - 保存成功后刷新应用配置、返回首页，并通过 Snackbar 提示保存成功。
3. 轻量 UI 动画：
   - 主页面切换使用 Compose 动画。
   - 消息块淡入淡出。
   - 曲谱列表与队列列表的选中态、编号和颜色变化使用轻量动画。
4. 收尾：
   - 补充 JVM 单元测试。
   - README 开发节点追加 Step11 记录。
   - 版本更新到 `v1.3.0`，`versionCode` 更新到 `7`。

## 范围外
- 不引入 Navigation Compose、ViewModel、新图标库或新依赖。
- 不改变运行时播放调度、触控注入、悬浮窗服务或权限判断语义。
- 不实现 notes 的逐字符/小节级精确错误定位。
- 不迁移旧播放配置文件格式。

## 验收
- 导入非法 JSON 时提示包含行列信息，且不写入曲谱文件。
- 严格校验失败时能看到失败字段，字段存在时尽量显示行列位置。
- 队列模式可按点击顺序选择、取消曲谱，保存后队列顺序与旧 `queueText` 规则一致。
- 播放配置保存成功后返回首页，并显示“设置已保存”Snackbar；保存失败仍停留原页显示错误。
- `gradlew.bat :app:testDebugUnitTest :app:assembleDebug` 通过。
