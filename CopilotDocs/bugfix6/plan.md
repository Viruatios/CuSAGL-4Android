# Bugfix6 Plan: 曲谱校验错误文案可读化

## 目标
- 修复 Step11 后曲谱 JSON 校验错误在应用内直接展示字段名和行列位置的问题。
- 将用户可见错误改为能对应到填空栏目的自然语言提示，例如“曲谱名为空”。
- 保留 JSON 语法错误的行列提示，因为语法错误通常无法可靠映射到具体字段。
- 追加修复：当错误能对应到手动创建曲谱的填写栏目时，将该栏目显示为红色错误状态；出现曲谱校验错误时，页面自动滚动到错误提示位置。

## 范围内
1. `ScoreParser.parseScoreTextStrict` 严格校验失败文案：
   - `name` 为空：曲谱名为空。
   - `bpm` 缺失、非数字或非正数：BPM 必须是正整数。
   - `time_signature` 缺失或非法：拍号格式错误，请使用类似 4/4 的格式。
   - `notes` 缺失或为空：曲谱内容为空。
   - `notes` 存在但解析不出音符：曲谱内容无法解析，请检查 notes 填写。
   - JSON 语法错误：JSON 格式错误，保留行列位置。
2. 同步中英文字符串资源。
3. 更新 JVM 单元测试，覆盖导入和严格解析的可读错误。
4. README 追加 bugfix6 记录，版本更新到 `v1.3.1`，`versionCode` 更新到 `8`。
5. 追加 UI 行为：
   - 手动创建页根据错误资源映射到曲名、BPM、拍号或 notes 栏目，并用 `OutlinedTextField(isError = true)` 标记。
   - 错误消息出现时，曲谱管理页与手动创建页滚动到顶部错误提示区域。

## 范围外
- 不改变曲谱解析、保存、覆盖或缓存清理规则。
- 不调整 Step11 的队列复选框、Snackbar 或动画实现。
- 不更新 `AGENTS.md`，因为本次不改变长期项目约定。
- 不为导入 JSON 增加字段级编辑器；导入失败只滚动到页面错误提示。

## 验收
- 用户看到的是栏目语义错误，而不是 `name`、`line/column` 这类技术字段。
- 非法 JSON 仍显示第几行第几列附近，便于修 JSON 格式。
- `gradlew.bat :app:testDebugUnitTest :app:assembleDebug` 通过。
